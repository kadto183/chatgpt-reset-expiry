# ChatGPT 重置额度有效期查询插件

如果 ChatGPT 只显示“某天到期”，这个脚本可以进一步显示**具体到几点几分几秒的失效时间**。

## 功能

- 查询 ChatGPT 重置额度（Reset Credits）的准确有效期
- 显示精确到秒的失效时间
- 自动转换为浏览器当前本地时区
- 自动处理 UTC 偏移与夏令时
- 默认保持最小化，检测到有效额度后再显示结果
- 主界面只显示仍然有效的额度
- 已失效额度与其他检测结果收进“更多信息”
- 支持拖动悬浮窗并记住位置
- 自动适配深色 / 浅色主题
- 支持一键复制全部有效额度时间

## 隐私与安全

本脚本仅在浏览器本地运行：

- 不上传账号数据
- 不保存 Cookie、Token 或登录凭据
- 不主动重放 ChatGPT 的受保护请求
- 不修改 ChatGPT 账号设置
- 仅读取 ChatGPT 页面自身已经收到的响应数据

## 语言与时区

- 中国大陆时区：简体中文
- 中国香港、中国澳门、中国台湾时区：繁体中文
- 其他地区：英文
- 时间始终按浏览器 / 操作系统当前时区显示
