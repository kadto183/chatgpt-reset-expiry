# ChatGPT 리셋 크레딧 만료 시간 확인 도구

ChatGPT **Reset Credits가 정확히 몇 시 몇 분 몇 초에 만료되는지** 확인하는 사용자 스크립트입니다.

ChatGPT가 날짜만 표시하는 경우에도 각 크레딧의 정확한 만료 시각을 브라우저의 현지 시간대로 표시합니다.

## 주요 기능

- Reset Credits의 정확한 만료 시각 표시
- 브라우저 현지 시간대로 자동 변환
- UTC 오프셋 및 일광 절약 시간 자동 처리
- 유효한 크레딧만 메인 화면에 표시
- 만료된 항목과 진단 정보는 More 영역에 접어두기
- 창 드래그 및 위치 기억
- 다크 / 라이트 테마 자동 적용
- 유효한 만료 시간을 한 번에 복사
