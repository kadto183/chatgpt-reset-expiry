# ChatGPT 重置額度有效期查詢插件

如果 ChatGPT 只顯示「某天到期」，這個腳本可以進一步顯示**具體到幾點幾分幾秒的失效時間**。

## 功能

- 查詢 ChatGPT 重置額度（Reset Credits）的準確有效期
- 顯示精確到秒的失效時間
- 自動轉換為瀏覽器目前本地時區
- 自動處理 UTC 偏移與日光節約時間
- 預設保持最小化，偵測到有效額度後再顯示結果
- 主介面只顯示仍然有效的額度
- 已失效額度與其他偵測結果收進「更多資訊」
- 支援拖曳懸浮視窗並記住位置
- 自動適配深色 / 淺色主題
- 支援一鍵複製全部有效額度時間

## 隱私與安全

本腳本只在瀏覽器本地執行：

- 不上傳帳號資料
- 不儲存 Cookie、Token 或登入憑證
- 不主動重放 ChatGPT 的受保護請求
- 不修改 ChatGPT 帳號設定
- 只讀取 ChatGPT 頁面本身已收到的回應資料

## 語言與時區

- 中國大陸時區：簡體中文
- 中國香港、中國澳門、中國台灣時區：繁體中文
- 其他地區：英文
- 時間始終按瀏覽器 / 作業系統目前時區顯示
