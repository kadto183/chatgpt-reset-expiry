# ChatGPT 重置額度有效期查詢外掛

用來查詢 **ChatGPT 重置額度（Reset Credits）具體在幾點幾分幾秒失效**。

如果 ChatGPT 頁面只顯示「某天到期」，此外掛會讀取頁面已經收到的資料，並顯示更精確的失效時間。

## 主要功能

- 查詢 ChatGPT 重置額度的準確有效期
- 精確顯示到秒
- 自動換算為瀏覽器目前本地時區
- 自動處理 UTC 偏移與日光節約時間
- 預設最小化，只在偵測到有效額度後顯示結果
- 主介面只顯示仍然有效的額度
- 已失效額度與診斷資訊收進「更多資訊」
- 支援拖曳視窗並記住位置
- 自動適配深色 / 淺色主題
- 一鍵複製全部有效額度時間

## 隱私與安全

- 不上傳帳號資料
- 不儲存 Cookie、Token 或登入憑證
- 不主動重放 ChatGPT 的受保護請求
- 不修改 ChatGPT 帳號設定
- 只讀取 ChatGPT 頁面已經收到的回應資料
