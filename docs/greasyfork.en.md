# ChatGPT Reset Expiry

A userscript for checking the **exact expiration time of ChatGPT Reset Credits**, down to the second.

If ChatGPT only shows the expiration date, this tool reveals the precise local time when each reset credit expires.

## Features

- Shows the exact expiration time of ChatGPT Reset Credits
- Converts timestamps to the browser's local timezone
- Handles UTC offsets and daylight saving time automatically
- Starts collapsed and only surfaces results after valid data is detected
- Keeps the main panel focused on active credits
- Moves expired credits and diagnostics into a collapsed More section
- Supports dragging and remembers the panel position
- Adapts automatically to light and dark themes
- Copies all active expiration times with one click

## Privacy

- No account data is uploaded
- Cookies, tokens, and login credentials are not stored
- Protected ChatGPT requests are not replayed
- ChatGPT account settings are not modified
- The script only inspects response data already received by the ChatGPT page
