# ChatGPT リセットクレジット有効期限確認ツール

ChatGPT の **Reset Credits が何時何分何秒に失効するか** を確認するユーザースクリプトです。

ChatGPT が有効期限の日付しか表示しない場合でも、各クレジットの正確な失効時刻をブラウザのローカルタイムゾーンで表示します。

## 主な機能

- Reset Credits の正確な失効時刻を表示
- ブラウザのローカルタイムゾーンへ自動変換
- UTC オフセットと夏時間に自動対応
- 有効なクレジットだけをメイン画面に表示
- 期限切れデータと診断情報は「More」に折りたたみ
- ウィンドウをドラッグでき、位置を記憶
- ダーク / ライトテーマに自動対応
- 有効な期限をワンクリックでコピー
